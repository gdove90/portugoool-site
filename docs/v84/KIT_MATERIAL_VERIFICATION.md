# Kit base verification

Owner-selected base: ST720, listed by Apliiq as Sustainable Athletic Tee and by the manufacturer as Sport-Tek PosiCharge Re-Compete Tee.
Manufacturer confirms 3.8-ounce, 100% recycled polyester, moisture-wicking fabric, athletic fit, taped neck, set-in sleeves and tear-away label. Public copy must omit supplier names and style codes.

The supplier's product-specific decoration options include DTF transfer, embroidery and bulk screen printing. A generic digital-print navigation label is not proof of DTG compatibility. Prefer a DTF quote for the approved 10+ intake; do not promise bulk screen-print minimums, placements, finished dimensions or decoration compatibility without the selected-method quote.

Manufacturer range includes XS..4XL, while the inspected supplier catalog listed XS..3XL. 4XL fulfillment is not verified. The six reference colors have manufacturer listings: Black, True Royal, Iron Grey, True Red, Silver and White. Stock and exact decoration dimensions require quote-time confirmation.

The reference body-chest size table exactly matches the manufacturer's current specification: XS 32..34, S 35..37, M 38..40, L 41..43, XL 44..46, 2XL 47..49, 3XL 50..53 and 4XL 54..57 inches. These are body measurements, not flat garment measurements. A listed size remains subject to supplier availability at quote time.
