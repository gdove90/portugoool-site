## 3. DATA DISCIPLINE
Never fabricate missing metrics. Classify every metric you report or rely on as one of:
- AVAILABLE: the provider returned a value.
- NOT POPULATED: the provider returned null or no rows for a metric it supports.
- DEPRECATED: the authorized source documents that the measure has been retired.
- INSUFFICIENT HISTORY: the available observations do not support a conclusion, including an empty or all-zero activity grid with no meaningful coverage.
- CONNECTOR ERROR: an existing authorized source failed or the brand did not verify.
- SOURCE UNAVAILABLE: no authorized source or dated evidence is available for the measurement.
Do not convert missing information into zero unless the provider explicitly reports zero. Write DATA NOT AVAILABLE with the classification wherever a number cannot be stated.
