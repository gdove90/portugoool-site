# Goool Athletics avatars ("Grok models")

Four fixed people used in every Goool commercial, social asset and product mockup. Never invent a fifth. Never paraphrase a character card; paste it exactly.

Folder:
  greg/    greg_front.png  greg_back.png  greg_left.png  greg_right.png
  jeff/    jeff_front.png  jeff_back.png  jeff_left.png  jeff_right.png
  alex/    alex_front.png  alex_back.png  alex_left.png  alex_right.png  alex_movement.mp4
  andrew/  andrew_front.png andrew_back.png andrew_left.png andrew_right.png
  AVATARS.md   roster, source file per view, pixel size, THUMBNAIL flags
  PROMPTS.md   the exact Grok Imagine prompts that made them
  README.md    this file

Rules:
- Minimum usable size is 1024 px on the long edge. Anything flagged THUMBNAIL in AVATARS.md is a placeholder only.
- Base wardrobe in every source image is a plain heather-grey crew tee, black athletic shorts, white low-tops. Goool product is overlaid on top; the base garments are never shown in final assets.
- Aspect ratio of source images is 2:3. Final social output is 9:16 for Reels, Stories, TikTok and 2:3 cropped to 4:5 for feed.
- When Higgsfield or Claude Design needs one of these people, they receive: the character card from PROMPTS.md, the four view files, and the name. Nothing else.
