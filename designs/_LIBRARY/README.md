## Read this before planning anything from the spec sheets

**15 of the 24 sheets specify a method Apliiq cannot run.** Apliiq offers
**transfer print (DTF)** and **embroidery**. That is the whole list. DTG,
sublimation, heat-transfer vinyl and HD silicone all appear across the set
and none are available.

**"Comfort Colors 4810GD" appears 12 times and names two different makers.**
4810GD is Bella+Canvas. Comfort Colors is C1717.

Per-design tables, marked runnable or not, are in
`3-tee-designs/README.md` and `7-kit-sponsorship/README.md`. The same data
is in `SPECS.json` in each folder if you want to sort or search it.
