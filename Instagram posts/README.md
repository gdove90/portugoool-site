# Instagram posts

Every picture and clip we make for Instagram lives here, sorted by
where it runs. The models stay in `brand-assets/avatars/`. Nothing goes
live from anywhere else. Rejected Grok outputs are kept too, with
REJECTED in the name, so nothing from a session is lost.

```
Instagram posts/            (at the top of the GOOOL folder)
  feed/     4:5, 1080 x 1350 (the 2:3 source is kept next to the crop)
  stories/  9:16, 1080 x 1920, safe zone 250 px top and bottom
  reels/    9:16, 1080 x 1920 video, plus its cover frame
  README.md
```

File names: `YYYY-MM-DD_<what-it-is>_<size>.<ext>`, for example
`2026-09-30_stacked-cap-ledge_1080x1350.jpg`. Keep the untouched source
beside it as `_source-2x3` (or whatever the source ratio is).

Before anything posts:

- The real vector lockup is laid over any generated mark in Claude Design.
  Generated lettering is never posted as is.
- Only the four avatars appear as people (`brand-assets/avatars/`).
- Only products we sell, in colourways we sell, described as the site
  describes them.
- Copy: WEAR THE FEELING. Soccer or futbol, never football. No prices on
  screen. Offer line, when used: "20% off your first order. Sign up at
  goool.shop". No supplier names, crests, balls with federation marks,
  or other logos.
- Generated lifestyle images are for social only, never the product page.
