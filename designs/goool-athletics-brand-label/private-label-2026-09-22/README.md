# GOOOL private label — selected artwork

`GOOOL-PRIVATE-LABEL-FINAL-300x300.png` is the file to upload to Apliiq.
It is option **A, traditional**: the GOOOL wordmark over the
three-segment rule. Owner selected it on 2026-09-22.

## Apliiq service

Private label, **$2.50 per unit**, available on demand with no minimums
and no subscription. It **removes the manufacturer's brand label** and
sews in a white satin loop tag carrying this artwork.

The thing that decided the whole question: Apliiq states *"you provide
the logo, Apliiq generates required garment information."* So the brand
name, size, fibre content, care instructions and country of origin are
produced by Apliiq. We do not have to fit legal text onto a one-inch
tag, and we do **not** additionally need the $2.50 neck print to be
compliant. One service, not two.

## Spec this file meets

| | |
|---|---|
| Canvas | 300 × 300 px = 1" × 1" at 300 dpi |
| Ink | **black only** |
| Background | transparent — bare white satin shows through |
| Thinnest stroke | 0.51 mm |

**Black ink is not a style choice.** Apliiq: *"private labels print in
black ink only, color artwork will be converted to grayscale."* The red
segment of the brand rule (#C61322) is set to black in this file
deliberately: left as red it would have been converted to mid-grey and
printed washed out on white satin.

## Why A and not B

Option B stacked GOOOL / rule / ATHLETICS. Its ATHLETICS band measures
**0.25 mm** at one inch, roughly half what is safe to send to a
heat-transfer satin tag without a physical proof. A is also the mark
already on the chest of the Casual Wordmark Tee, so the tag echoes the
garment. Apliiq's own guidance asks for "a simple, bold brand mark".

B is kept in this folder as `LABEL-B-ATHLETICS-300x300.png`. If it is
ever revisited, ATHLETICS needs thickening or wider letterspacing
first; do not send it as drawn.

## Before ordering

Two caveats carried forward from the earlier label work, both still
open:

1. Apliiq's private label is a **printed satin tag, not woven**. It
   will not have the woven texture of the original tag concept.
2. Stroke measurement on this project has been unreliable before — a
   previous automated check called three artworks a FAIL and a physical
   sample disproved it. 0.51 mm should hold, but the first order is the
   real proof.

`PROOF-SHEET-actual-size.png` shows both options on satin at actual
size and at 3×.

## Decision and status — 2026-09-22

**Selected: private label.** Owner chose it over the neck print
knowing the trade, and deferred the purchase to **Friday 2026-09-25**.

Why private label rather than the cheaper cash-flow option:

| | Cost model | Manufacturer tag |
|---|---|---|
| Neck print | pay as you go, nothing upfront | **stays sewn in** |
| **Private label** | **buy supply upfront** | **removed** |

The neck print is listed "in stock 1000 · pay as you go", so it bills
per garment at fulfilment with no inventory to buy. It is the easier
option on cash. It was rejected because it does not remove the
Bella+Canvas tag, which leaves a blank manufacturer's label sitting
next to GOOOL branding inside the neck.
